# container-ci

container-ci runs every GitLab CI job in its own fresh Apple `container` on a Mac with Apple
silicon. This package holds `gitlab-container-executor`, the custom executor that GitLab Runner
calls for each stage of a job.

It requires Apple `container` 1.0.0 or newer on macOS 26. Tested with 1.5.0.

container-ci is an independent project. It is not affiliated with or endorsed by GitLab Inc.

## Install

Install the package behind a link, so the runner keeps one path across upgrades:

```bash
ocx package install --link ~/.container-ci/executor ghcr.io/extra-code/container-ci:<version>
```

Point `config_exec`, `prepare_exec`, `run_exec` and `cleanup_exec` in the runner's `config.toml`
at `~/.container-ci/executor/content/bin/gitlab-container-executor`, with the home directory
written out.
The [README](https://github.com/extra-code/container-ci#register-the-runner) shows the full
runner configuration and how to verify the package's signature.

## Update

Re-run the install line with the new version. The link moves to it, and the old version stays in
the store until `ocx clean`.
